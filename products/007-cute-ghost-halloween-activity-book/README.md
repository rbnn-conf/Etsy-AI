# Product #007 — Cute Ghost Halloween Activity Book

The owner's handoff called this "Product #006" (source ZIP
`product-006-cute-ghost-halloween-final-30.zip`). It is numbered 007 here because
`products/006-minimalist-budget-and-goals-planner/` already exists.

`source/` holds the 30 supplied PNGs and `MANIFEST.txt`, byte-identical to the
ZIP. They are authoritative artwork: never regenerated, redrawn or edited.
`page-map.json` binds each page ID (P001–P030) to its file, title, activity type
and SHA-256.

## Pipeline

From the repository root (Node 24+):

```powershell
node products/007-cute-ghost-halloween-activity-book/src/build.mjs
node products/007-cute-ghost-halloween-activity-book/src/marketing.mjs
node products/007-cute-ghost-halloween-activity-book/src/marketing-layout.mjs
node products/007-cute-ghost-halloween-activity-book/src/qc.mjs
npm.cmd --prefix products/007-cute-ghost-halloween-activity-book test
npm.cmd --prefix products/007-cute-ghost-halloween-activity-book run review   # Telegram, PNG previews only
```

The scripts reuse Product #004's primitives (PNG validation, contain placement,
PDF book, lossless ZIP bundling), Product #003's pdf.js renderer and the shared
`marketing/` Chromium renderer. None of those files were modified and no new
dependencies were installed. The orchestration (30 pages, mixed orientations,
delivery set) is specific to this product.

## Print decisions

- **Contain fit, 12 mm white margins, 152 PPI canvas.** Every portrait page
  (1103×1426 / 1086×1448) sits at native pixels, about 185 mm wide on A4. P002 is
  landscape (1448×1086) and is scaled down to fit a portrait page.
- **Resolution: PASS WITH NOTICE.** These are not 300-DPI files. Copy says
  "high-quality printable digital files". Nothing is upscaled.
- **Delivery:** A4 PDF, US Letter PDF, 30 original PNG pages and a printing guide,
  in five ZIPs of 19 MB or less. Two per-size lossless PNG sets (~100 MB) cannot
  fit Etsy's 5 × 20 MB limit, so the PNGs are the original artwork, byte-identical.
  The PDFs embed each page at native size as JPEG q95 4:4:4. Lossless PDFs were
  48.6 MB each, too big to fit alongside the PNGs.

## Outputs (git-ignored)

- `output/deliverables/`: the two PDFs and the guide.
- `output/etsy/`: **upload only these ZIPs.**
- `output/marketing/`: ten 2000×2000 listing images, 01–10.
- `previews/`: per-size page layout previews (QC and Telegram).
- `qc/`: build and production reports, source audit, contact sheets, PDF renders.
  `qc/VISUAL_QA.md` is tracked and records the human-style inspection and blockers.
- `listing/listing.json` (tracked) is the title, tags, category and description.
  `listing/LISTING.md` is regenerated by QC with the upload list.
