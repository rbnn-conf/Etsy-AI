# LumiumX Etsy Shop Design System

**Version:** 1.0.0\
**Brand:** LumiumX\
**Purpose:** Visual specification for the LumiumX Etsy Shop Home,
banner, listing imagery, featured products and supporting brand assets.

------------------------------------------------------------------------

## 1. Brand Direction

### Brand Positioning

LumiumX is a premium digital-product brand creating useful, beautifully
designed tools for planning, organisation, finance and everyday life.

### Brand Promise

> **Beautifully designed tools for a more organized life.**

### Brand Personality

-   Minimal
-   Warm
-   Editorial
-   Premium
-   Calm
-   Intelligent
-   Purposeful
-   Timeless
-   Practical

-   Generic Etsy printable aesthetics
-   Bright rainbow palettes

-   Cartoon graphics
-   Heavy icon usage
-   Cluttered layouts

-   Neon colours
-   Excessive gradients

# 2. Core Colour Palette

  Name          Hex         Primary Use
  ------------- ----------- ---------------------------------------------
  Ink           `#1F1F1F`   Main text, logo, headings
  Warm Ivory    `#FAF7F2`   Primary background, banner
  Paper White   `#FFFFFF`   Cards, product backgrounds
  Stone         `#E6E1D9`   Borders, dividers, secondary surfaces
  Terracotta    `#C4644A`   Primary accent, highlights, CTA accents
  Sage          `#7E8A7B`   Secondary accent, selected product families

### Colour Ratio

Default LumiumX composition:

-   **60% Warm Ivory**
-   **20% Paper White**
-   **15% Ink**
-   **5% accent**

The accent should normally be either **Terracotta** or **Sage**, not
both heavily at the same time.

### Colour Rules

**Warm Ivory** is the default LumiumX canvas.

**Ink** is the primary text colour.

**Stone** should provide subtle separation without looking like a hard
grey border.

**Terracotta** is the signature brand accent.

**Sage** is an optional secondary accent for selected product
collections.

Avoid pure black (`#000000`) unless required for technical reasons.

# 3. Typography

## Display Typeface

**Spectral** or **Playfair Display**

Use for:

-   LumiumX wordmark
-   Major headings
-   Editorial statements
-   Large product titles

## Body Typeface

**Inter**

Use for:

-   Descriptions
-   Supporting text
-   Labels
-   Product information
-   Small UI-style text
-   Technical information

### Typography Hierarchy

``` text
LUMIUMX
Display / Serif
Large / elegant / generous spacing

Beautifully designed tools for a more organized life.
Inter / Regular

PLANNERS · TEMPLATES · TRACKERS · PRINTABLES
Inter / Medium / uppercase / letter spacing
```

### Typography Rules

-   Prefer generous whitespace.
-   Use uppercase sparingly.
-   Use letter spacing for small uppercase labels.
-   Do not use more than two font families.
-   Avoid decorative script fonts.
-   Avoid overly heavy bold typography.

# 16. Brand Consistency Rules

Every LumiumX asset should satisfy these rules:

### Rule 1 --- Recognisable

A LumiumX product should still look like LumiumX without the logo.

### Rule 2 --- Product First

The product must always be more visually important than decoration.

### Rule 3 --- Warm Neutral Foundation

Most assets should remain within:

`#FAF7F2` + `#FFFFFF` + `#1F1F1F`

### Rule 4 --- One Accent

Use one primary accent per asset.

### Rule 5 --- Editorial Typography

Use serif display typography + Inter body typography.

### Rule 6 --- Whitespace

Never fill empty space just because it is available.

### Rule 7 --- Real Product Previews

Whenever possible, show the actual product rather than a generic
representation.

### Rule 8 --- Consistent Photography

Mockups across the catalogue should appear to belong to the same
photography studio.

# 19. Automation Requirements

This design system should eventually become the source of truth for the
Faceless Etsy product pipeline.

For each new product, the system should generate:

``` text
PRODUCT
├── Product PDF
├── Product PNG preview
│
└── Etsy Assets
    ├── 01-hero.png
    ├── 02-whats-inside.png
    ├── 03-benefits.png
    ├── 04-lifestyle.png
    ├── 05-how-it-works.png
    └── 06-download-info.png
```

The renderer should inherit:

-   Brand colours
-   Typography
-   Spacing
-   Product family accent
-   Mockup style
-   Image composition
-   Logo placement
-   Background system

Claude should not invent a new visual identity for every product.

It should select from the LumiumX design system.
