# Reference 001 — Digital Budget Planner / Finance Tracker

- **URL:** https://www.etsy.com/uk/listing/1191641738/digital-budget-planner-finance-tracker
- **Category archetype:** mainstream "all-in-one" digital budget planner /
  finance tracker (PDF / digital-download; annual-planner adjacent).
- **Delivery:** instant digital download; print-at-home and/or use on a
  tablet.
- **Role in this library:** the baseline for the *digital PDF* end of the
  category — the listing most buyers compare everything else against.

## Neutral observations only

Recorded from the public listing surface as market signal. No copyrighted
text, imagery, or layout is reproduced here or anywhere in this repo.

- Positions as a complete money-management system (budget + tracker +
  reports), not a single worksheet.
- Listing imagery leads with a titled hero, then content-preview images, then
  a benefits/《what's included》image, then format/FAQ reassurance.
- Uses a soft, warm-leaning neutral palette with a single family accent —
  closer to "editorial" than the pastel-rainbow end of the category.
- Multi-page; the exact count is a listing detail and is not load-bearing for
  our analysis.
