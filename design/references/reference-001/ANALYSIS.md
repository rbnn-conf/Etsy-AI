# Reference 001 — analysis: Digital Budget Planner / Finance Tracker

Category-language extraction for the mainstream digital budget planner. This
describes *the category*, not this seller's assets.

## Colour behaviour
- Warm neutral ground (off-white / greige), **one** family accent applied to
  section headers, key figures and the progress elements.
- The stronger listings in this bracket keep the accent to a handful of
  placements; the weaker ones tint every header band and every category tag,
  which reads as a Canva default.
- Almost no pure white; almost no pure black. Warmth comes from the paper
  tone and the ink hue.

## Typography relationship
- A serif or high-contrast display face for the product title and section
  titles, paired with a neutral sans for tables, labels and numbers.
- Numbers are treated as content: tabular alignment, right-aligned currency.
- The category tell of a *cheap* product is a single rounded "friendly" sans
  doing both jobs, with no real size jump between levels.

## Layout density
- Balanced-to-dense. A "dashboard/overview" page up front that is mostly
  summary figures, then denser ledger pages, then a review page.
- Best-in-class alternates density deliberately; the rest repeat one table
  layout on every page.

## Hierarchy
- The overview page's bottom-line number (leftover / net) is the intended
  focal point and is sized up.
- On ledger pages the hierarchy is: page title → column header row → rows →
  total row, carried by weight and a heavier rule on the total.

## Whitespace
- Generous outer margins; tight, rhythmic row spacing inside tables.
- Weakness across the category: a large undesigned gap under the page title on
  the lighter pages because a short block got vertically centred.

## Component style
- Summary "stat" blocks, ledger tables, a progress indicator for savings/debt,
  check/tick affordances, a notes area.
- Over-designed versions wrap each stat in a rounded, shadowed, tinted card —
  the single biggest "template" signal in this bracket.

## Visual merchandising / mockup strategy
- Listing set: hero → inside-the-product previews → what's-included → benefits
  → formats/FAQ.
- Mockups are usually a tablet or a framed page on a warm desk with sparse
  props (pen, coffee, plant). The credible ones keep lighting and shadow
  consistent across every image ("same studio"); the rest mix flat
  screenshots with 3D device renders.

## Commercial communication
- Sells "control / calm / see-everything-in-one-place".
- Reassurance images (formats, instant download, nothing shipped, undated /
  reusable) do measurable work in this price band.

## Strengths to adopt
- The **sequence** (what it is → why → what you get → how / formats).
- **Restrained palette**, one accent, warm neutral ground.
- **Real content previews** cropped to the meaningful region.
- A genuine **overview/dashboard** page distinct from the ledgers.
- Consistent mockup lighting across the whole set.

## Weaknesses LumiumX deliberately avoids
- Accent on every header band and every category tag (→ `ANTI_PATTERNS.md` B3).
- Rounded, shadowed, tinted stat cards (→ B10 / D1).
- One rounded sans doing display + body, flat hierarchy (→ C1 / C2).
- Money/coin icons and rainbow category colours (→ B2 / B7 / B8).
- Blank-grid preview images (→ E4).
- Vertically-centred title with a dead gap beneath (→ D2).

## The opening this reference points to
A financial **journal**, not a tracker UI: ivory + charcoal, Spectral + Inter,
terracotta used ~4 times per asset, hairline tables (no boxed cells), and the
overview page rebuilt as a KPI *statement* with one dominant serif figure.
