# Reference 003 — analysis: GoodNotes-style Digital Budget Planner

Category-language extraction for the tablet-first hyperlinked planner.
Describes *the category*, not this seller's assets.

## Colour behaviour
- Screen-first, so more colour is tolerated — but the *premium* listings in
  this bracket are still restrained: a warm neutral ground, one accent, tabs
  in a muted tone.
- Multiple colourways is a merchandising tactic, not a design idea; each
  colourway keeps the same neutral base and swaps one accent.
- The cheap tell here is a saturated cover + rainbow tabs + bright section
  fills that vibrate on an OLED screen.

## Typography relationship
- Larger type overall (viewing distance + touch), a display serif on the
  cover and section headers, a clean sans for everything tappable.
- Numbers still tabular; on-screen the temptation is a thin weight that
  disappears — the good listings keep body at 400+ and headers at 600.

## Layout density
- Lower than the print packs. Each screen is one task; scrolling is avoided in
  favour of paging via tabs.
- An index / home screen is the hub; every page links back to it.

## Hierarchy
- Cover → index → section landing → worksheet. The index is the true focal
  page and is designed like a contents page.
- Within a worksheet: one clear title, a single primary action area, a
  back-to-index affordance.

## Whitespace
- Generous — screen real estate is cheap and touch targets need room.
- The failure mode is an index page that is a plain bulleted list rather than
  a designed contents page.

## Component style
- Tab bar / side index, hyperlinked contents, section landing pages, KPI
  tiles, and the same ledger/summary/progress components as the rest of the
  category.
- Navigation is the component that justifies the price premium versus a flat
  PDF.

## Visual merchandising / mockup strategy
- Listing leads with a **cover on a tablet** hero, then screen previews in a
  device frame, then a "how the tabs work" image, then colourway options.
- Device mockups are unavoidable here; the credible ones use one clean
  tablet render with consistent lighting, never a browser window and never
  three-dot chrome.

## Commercial communication
- Sells "an app-like experience without an app / subscription" — navigation,
  reusability, works in the app you already use.
- "Hyperlinked", "undated", "works in GoodNotes/Notability" are the
  load-bearing claims.

## Strengths to adopt
- A **designed index/contents page** as a genuine hub (maps to our
  `navigation` component + the "Quick Start & Key" page).
- Larger, confident type; real hierarchy at viewing distance.
- One-task-per-screen restraint.
- Colourway discipline: neutral base constant, one accent varies (this is
  exactly the LumiumX family-accent system).
- One clean device render, consistent lighting.

## Weaknesses LumiumX deliberately avoids
- Saturated cover + rainbow tabs + bright section fills (→ `ANTI_PATTERNS.md`
  B1 / B2 / B4).
- A "premium" claim resting on a decorated cover rather than the pages
  (→ F3).
- Index page as a plain bullet list (→ D2 / A1 for the marketing "how it
  works").
- Device frames with browser chrome / three dots (→ D7).
- Thin on-screen body weight that fails contrast (→ C3 / accessibility).

## The opening this reference points to
LumiumX borrows the **navigation-as-value** idea and the **colourway
discipline**, but stays print-first and editorial: the "index" is a
contents-page composition (numbered, hairline-separated), type is Spectral +
Inter at a confident scale, and the only cover is the hero listing image —
the pages carry the premium, not a branded cover.
