# Reference 003 — Digital Budget Planner, GoodNotes, Finance

- **URL:** https://www.etsy.com/uk/listing/1829349409/digital-budget-planner-goodnotes-finance
- **Category archetype:** tablet-first hyperlinked digital planner — designed
  for GoodNotes / Notability / annotation apps, with tabbed navigation and a
  branded cover.
- **Delivery:** instant digital download; PDF with internal hyperlinks, used
  on an iPad/tablet with a stylus.
- **Role in this library:** the *tablet-digital* end of the category — where
  navigation, cover branding, and screen legibility dominate the design.

## Neutral observations only

Market signal only. No copyrighted text, imagery, or layout reproduced.

- Built around hyperlinked tabs / an index page — navigation is a first-class
  feature and a stated selling point.
- Has a designed **cover** (the listing's brand surface), unlike the
  print-first packs.
- Screen-first: contrast, tap-target size and tab legibility matter more than
  ink cost.
- Often sold as dated + undated variants and in multiple colourways.

## Do / don't

- **Do** study how navigation and a cover create a premium, "app-like"
  perception.
- **Don't** reproduce its cover, tab system, colourways, page templates, or
  copy. Extract category language only — see `ANALYSIS.md`.
