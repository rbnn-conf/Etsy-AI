# Reference 002 — analysis: Printable Paycheck Budget Planner (A4 pack)

Category-language extraction for the print-first end of the budgeting
category. Describes *the category*, not this seller's assets.

## Colour behaviour
- Minimal by necessity: home-printer ink cost is a real, frequently-cited
  review complaint, so the strong listings use line work on white/near-white
  with one accent that still reads in greyscale.
- Weak listings still ship pastel header fills and full-bleed tints, then
  caption the listing "ink friendly" — a credibility gap.

## Typography relationship
- One family, two weights (regular + semibold) is the norm and is *correct*
  here — script/display faces print poorly on inkjet/laser and undercut
  "professional".
- The premium move is not more fonts; it is a real size/weight jump between
  page title, section label, and body, plus a disciplined tracked-caps label.

## Layout density
- Dense. A fixed pack sells on *how much you get*, so pages carry a lot of
  rows. Row height and currency-cell width are the binding constraints.
- A4 and US Letter must be laid out **independently** — the common failure is
  one file scaled, giving tables that run off the Letter page or odd margins.

## Hierarchy
- Page title → shared header band (title + period field) → table → total.
- The header band repeated identically on every page is what lets pages be
  reprinted or reordered without confusion — a genuine system property, not
  decoration.

## Whitespace
- Outer margin is a *print* decision (≥10mm, most home printers can't
  full-bleed). Internal whitespace is tight and rhythmic.
- Over-minimal versions leave half a page blank and call it "clean"; buyers
  read that as low value for a paid pack.

## Component style
- Shared header band, hairline tables, checkboxes, a small progress shade-in,
  blank custom rows on every list page (real budgets don't match a template's
  presets).
- The "shade-in progress" strip is the one place a hand-filled product earns
  a spot of accent.

## Visual merchandising / mockup strategy
- Listing leads with a hero stating the page count and A4, then a grid or
  fan of the actual pages, then a benefits image, then a print/format image.
- Mockups are printed pages on a plain warm surface — physical, believable,
  no device frames.

## Commercial communication
- Sells "everything you need, on paper, print once, reuse". Page count,
  "undated", "A4 + US Letter", and "print at home" are the load-bearing
  claims.

## Strengths to adopt
- **Ink economy as a design constraint**, not an afterthought.
- **Independent A4 / Letter** layouts; identical content, tuned dimensions.
- One family + real size/weight hierarchy proving you don't need decoration.
- Shared header band for reorder/reprint resilience.
- Blank custom rows on every list page.
- Physical printed-page mockups with consistent lighting.

## Weaknesses LumiumX deliberately avoids
- Pastel header fills / full-bleed tints on a product sold as "ink friendly"
  (→ `ANTI_PATTERNS.md` B1 / E1).
- Selling page count while making every page the same table (→ A4 / D8).
- "Minimalist" used as an excuse for half-empty pages (→ D5 inverted / F4).
- Scaling one canvas to the other size (→ D-print / reference note).

## The opening this reference points to
LumiumX keeps the print discipline (line work, ink economy, independent
variants, shared header band) but lifts the register: Spectral title + a
tracked-caps kicker motif, hairline tables with no fills, terracotta only on
the kicker mark, the one key figure, and the shade-in strips — a pack that
prints cheap and still reads as a premium journal.
