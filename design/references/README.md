# Market reference library

Curated references that define the **visual category** for LumiumX products.
They are market research, not templates.

> **Do not clone, copy, reproduce, trace, or imitate any individual seller's
> assets, wording, branding, illustrations, page layouts, or proprietary
> elements.** Extract the underlying *commercially useful design language* —
> what the category signals, what it over-uses, where the gap is — so the
> Creative Director understands the category rather than reproducing a seller.

## Structure

```
design/references/
  reference-001/  SOURCE.md   URL + neutral, observable facts (format, stated page count, delivery)
                  ANALYSIS.md  category design-language extraction (the useful part)
  reference-002/  …
  reference-003/  …
```

`ANALYSIS.md` covers: colour behaviour · typography relationship · layout
density · hierarchy · whitespace · component style · visual merchandising ·
mockup strategy · product presentation · commercial communication · strengths
· weaknesses · **what LumiumX adopts** · **what LumiumX deliberately avoids**.

## The three initial references

| ID | Category archetype it represents |

| reference-001 | Digital budget planner / finance tracker — the mainstream "all-in-one money tracker" listing |
| reference-002 | Printable paycheck / pay-period budget planner — print-first, multi-page A4 pack |

Together they bracket the category: PDF-digital, print, and tablet-digital.
The Creative Director reads all three `ANALYSIS.md` files (via
`CREATIVE_BRIEF.reference_analyses`) before selecting a direction.

## The LumiumX through-line (what all three tell us to do differently)

The category is saturated with **pastel Canva templates, coin/money icons,
rainbow category tags, rounded "friendly" fonts, and cover-led branding**. The
differentiation opening every reference points to is the same:

> Treat the product as a **premium financial journal** — editorial ink-on-ivory,
> one warm accent used scarcely, sophisticated serif display + clean sans
> functional type, hairline structure instead of boxed cells, and **real
> cropped page previews** instead of decorated mock-ups.
